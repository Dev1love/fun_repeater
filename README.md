# 🔊 Задом наперёд

Простая игра для телефона: один игрок записывает слово, второй слушает его **задом наперёд** и пытается повторить. Потом его повтор проигрывается задом наперёд — и если получилось исходное слово, значит угадал!

## Как играть

1. **🎙️ Записать слово** — Игрок 1 нажимает, говорит слово, нажимает ещё раз, чтобы остановить.
2. **⏪ Слушать задом наперёд** — Игрок 2 слушает перевёрнутую запись сколько угодно раз.
3. **🎤 Записать повтор** — Игрок 2 пытается повторить услышанные (перевёрнутые) звуки.
4. **🎯 Проверить слово** — повтор Игрока 2 проигрывается задом наперёд. Должно получиться исходное слово.

## Запуск

Это одностраничное приложение без сборки. Просто открой `index.html` в браузере телефона (нужен доступ к микрофону; на iOS/Android работает по HTTPS или с `localhost`).

Локально:

```bash
# любой статический сервер, например:
python3 -m http.server 8000
# затем открой http://localhost:8000
```

Технологии: `MediaRecorder` для записи и Web Audio API (`decodeAudioData` + переворот сэмплов) для воспроизведения задом наперёд. Внешних зависимостей нет.
